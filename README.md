# ☕ Kahve Fincanı Gelecek Yalanları Botu

> "Geleceği bilmek isteyenler için en güvenilir kaynak: Ben. Ama yalan söylüyorum."

## 🌟 Nedir Bu Şey?

Bu, insanlık tarihinin en önemli icadıdır. Kahve fincanınızın dibindeki telveyi okuyarak size geleceğinizi söyler. 

**Önemli Not:** Hiçbir şey okumaz. Her şeyi uydurur. Ama o kadar ikna edici bir şekilde uydurur ki, bir anlığına "acaba?" dersiniz. Sonra "yok ya" dersiniz. Sonra yine "acaba?" dersiniz. Bu döngü sonsuza kadar devam eder.

## 🚀 Nasıl Kullanılır?

1. Python yüklü olsun (yoksa yükle, çünkü bu bot onsuz çalışmaz, şaşırtıcı değil mi?).
2. `python falci.py` yaz.
3. Adını gir (veya uydur).
4. Bekle. Dramatik noktalar gelecek.
5. Falını al. Gül. Tekrar çalıştır. Yine gül.

```bash
python falci.py
```

## 📊 Özellikler

- ✅ Gerçekten çalışır
- ✅ Gerçekten yalan söyler
- ✅ Dramatik beklemeler içerir
- ✅ Türkçe konuşur (anadili gibi)
- ✅ Hiçbir bağımlılığı yok (sadece standart kütüphane)
- ✅ %100 işe yaramaz ama %100 eğlenceli
- ❌ Gerçek gelecek söylemez (bu bir özellik, bug değil)

## 🔮 Örnek Fal

```
Adınızı söyleyin: Kayyum

Fincanı çeviriyorum...
Telveyi inceliyorum...
Evrenin sırlarını çözüyorum (aslında uyduruyorum)...

🔮 FAL SONUCU:
   Kayyum, yakında çok büyük bir şey olacak. Muhtemelen bir paket çay bitmesi.
```

## 🤔 Neden Bu Repo Var?

Çünkü birileri "acaba kahve falını otomatik yapsak" diye düşündü. Sonra "hayır, daha saçma olsun" dedi. Ve işte buradayız.

Bu bot, modern dünyanın en büyük sorununa çözüm sunar: "Geleceğim ne olacak?" sorusuna "Bilmiyorum ama işte uydurdum" cevabını verir.

## 🚨 Uyarılar

- Bu botun söylediklerine inanmayın.
